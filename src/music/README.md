# Background music

Drop any `.mp3` files in here (e.g. `1.mp3`, `2.mp3`, `3.mp3`). The story
reading page picks one at random when you hit "Play Background Music" and
shuffles to a different one automatically each time a track ends.

No code changes needed to add, remove, or rename tracks — the page
discovers whatever `.mp3` files exist here at build/dev time.
